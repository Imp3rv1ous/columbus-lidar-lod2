# 步骤 6：建筑轮廓正则化

输入：`04_05_roof_planes/output_full/`（buildings_planes.laz、cues.csv 的脊线方向）
输出：`output/outlines_regularized.csv`（WKT ftUS + 逐楼质量指标）、
`outlines_regularized.obj`（CloudCompare 叠加线框）、QA 图两张。

## 方法（regularize_outlines.py）

1. **主方向 θ**：优先取该楼**屋脊/谷线的长度加权方向**（折算 mod 90°）——脊线是
   两个数百点最小二乘平面的解析交线，方向精度远高于毛边轮廓；无足够脊线的楼
   退回轮廓段方向直方图。每栋楼各自估计 θ（不假设全局网格，旋转建筑自动适配）。
2. **分段吸附**：全分辨率 marching-squares 轮廓 → Douglas–Peucker 分段（0.75 m）→
   与 θ / θ+90° 夹角 ≤15° 的段吸附为正交边；持续偏离的段保留自身方向
   （保护 45° 凸窗、非正交翼等真实斜边）。
3. **共线合并 + 定向重拟合**：同向相邻段合并，直线位置 = 支撑轮廓点在法向上的均值。
4. **重建**：相邻直线求交得角点；近平行邻线（<20°）插入垂直连接边。
5. **安全网**：自相交或面积变化 >25% 自动回退到 DP 简化轮廓并标记原因。

## 结果（2,261 栋）

- 成功正则化 **2,253 栋（99.65%）**，回退 8 栋（带原因码，DP 轮廓兜底）；
- 顶点数中位 **7**；平均偏移（原始轮廓→正则化多边形）中位 **0.15 m**（亚栅格级）；
- 正交边长度占比中位 **0.82**。

## 实现教训（记录）

首版全局米制坐标 + `np.allclose` 默认相对容差做 DP 顶点回溯匹配，在 ~10^5 量级
坐标下等效 ~1 m 误匹配容差，导致 38% 回退率与 0.64 m 系统偏移；改为局部坐标 +
精确匹配后回退率降至 0.35%、偏移降至 0.15 m。

## 毛尖修复记录（用户反馈驱动，2026-08-29）

用户在叠加检查中发现轮廓存在"凸出又收回"的尖刺伪影。根因与修复：
1. **交点过冲**：相邻两线夹角小/短斜边时，解析交点落到支撑范围外形成尖刺 →
   加过冲守卫（交点须距两侧支撑端点 ≤2.2 m，否则改用投影端点连接）；
2. **尖刺后处理**：顶点夹角 <40° 且相邻边 <5 m 的刺尖迭代删除；
3. **微 Z 形豁口**：近平行线小错位的连接边 → 新增近共线线合并
   （夹角 <20° 且错位 <0.4 m 的相邻线并为一条，长度加权定位）。
效果：<25° 尖刺 24 → **4**；<45° 角 → 36（含真实斜切角，占楼数 1.6%）；
成功率 2,260/2,261，偏移中位 0.16 m 不变。

## 零毛刺强制 + 遮挡建筑矩形先验（用户反馈第二轮，2026-08-29）

1. **零毛刺**：去除边长豁免，所有内角 <45° 的顶点迭代删除（含 DP 兜底轮廓）；
   全域 2,261 栋残余锐角 = **0**。依据用户领域先验：本区住宅不存在锐角建筑。
2. **矩形先验（遮挡补全）**：树穿透遮挡导致点云残缺的建筑，轮廓退化为圆钝团块。
   多证据评分门控（空洞率 >0.25 / 密度 <0.35 / 角度规整度 <0.6【内角落在 90°±25°
   的比例】/ 正则化失败），得分 ≥2 且矩形填充率 ≥0.62 时，用沿主方向 θ 的最小
   外接矩形替代。结果：regular 1,589 / **rect_prior 670** / dp_fallback 2；
   矩形案例抽检 12 例确认为合理补全（qa_rect_check.png）。
   已知代价：个别真实小凸出会被简化掉（method 列可筛出全部矩形案例复查）。

## 稳健定界（用户反馈第三轮，2026-08-29）

诉求：轮廓应由高密度屋顶主体主导，对稀疏飘点/小凸出鲁棒；遮挡裂块建筑按整体修正。
实现三机制（均有连通性/比例守卫，调参过程中的两次回归——稀疏楼塌缩、主体被切开——
已通过"最大连通块尺寸守卫"与"并集填充率"修复，过程记录于本节）：
1. 掩膜开运算削 1 格宽须边（守卫：最大连通块保 ≥80%、总量保 ≥80%，否则放弃）；
2. 矩形定界改边际密度直方图裁剪（两端 <10%·P90 的稀疏 bin 裁除，每轴上限 20%）——
   飘点与小门不再撑大矩形；
3. 掩膜裂成 ≥2 个大块（各 ≥ 最大块 25%）判为强遮挡证据 → 矩形框住大块并集
   （填充率按并集算，门槛 0.50）。
终版：regular 1,781 / rect_prior 480 / fallback 0；零毛刺保持；偏移中位 0.16 m。

## 裂缝仲裁与实例拆分（用户反馈第四轮，2026-08-29）

用户指出部分"大框"内的空隙实为两栋楼的分界。引入**物理仲裁判据**：两栋独立楼
之间是露天地面，激光穿过树冠会在缝内打到 DTM 高度的 class 2 点；单栋被遮楼的
缝下是实体屋面，无地面回波。对所有裂块建筑测"缝内地面命中率"（diagnose_splits.py）：
- **6 例命中率 0.91–1.00 → 确为两栋楼**（含用户指认的 id 228），已在 instance 层
  拆分（新 id 2296–2307），全下游链重跑；这些是第 2 步被树上误分类点桥接的
  欠分割漏网案例；
- id 307 / 216 掩膜在点级连通、未过地面测试 → 维持单栋判定（证据在案）。

## City3D 式多方向聚类（对齐论文实现）

方向吸附从"单主轴 θ/θ+90"升级为 **City3D §3.2 的方向聚类**：主轴仍取自屋脊线
（本管线对论文的改进），非主轴的持续边按方向聚类（10° 并簇、总长 ≥3 m 成簇），
每簇自带正交对轴——斜翼建筑的第二套轴向也被正则化。对齐边长占比中位升至 1.00。
